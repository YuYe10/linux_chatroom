# 🗨️ Linux聊天室项目

> 一个基于 C 语言开发的高性能多线程网络聊天室系统，支持多用户实时聊天、文件传输、用户管理等完整功能。

## 📋 项目概述

本项目采用**客户端-服务器架构**，通过多线程技术实现高并发处理，支持多个用户同时在线。系统集成了 MySQL 数据库进行用户管理，并提供完善的日志记录与信号处理机制。

---

## ✨ 主要功能

### 🔑 核心功能
- **用户注册/登录** - 安全的用户认证系统
- **实时群聊** - 支持多用户同时在线聊天
- **文件传输** - 支持文件上传与下载
- **在线用户管理** - 实时显示在线用户列表
- **用户状态** - 在线/隐身状态切换

### 🚀 高级功能
- **多线程并发** - 支持高并发客户端连接
- **数据库集成** - MySQL 存储用户信息
- **日志系统** - 详细运行日志记录
- **系统监控** - Fish 脚本实现的性能监控工具

## 🚀 快速开始

### 环境要求
- 🐧 Linux 操作系统
- 🔧 GCC 编译器
- 🗄️ MySQL 数据库服务器
- 🐟 Fish Shell（用于监控脚本）

### 编译步骤
```bash
# 1. 设置数据库密码环境变量
export CHATROOM_DB_PASS=your_mysql_password

# 2. 编译项目
make

# 或分别编译
make server  # 编译服务器
make client  # 编译客户端
```

### 运行方法
```bash
# 启动服务器（需要先启动MySQL服务）
./server

# 启动客户端（可启动多个实例）
./client
```

## 📖 使用指南

### 基本操作流程
1. 🚀 启动服务器：`./server`
2. 💻 启动客户端：`./client`
3. 🔐 选择注册或登录
4. 💬 开始聊天或使用其他功能

### 特殊命令
| 命令 | 功能 |
|------|------|
| `#exit` | 退出聊天室 |
| `#clear` | 清屏 |
| `#service` | 打开服务菜单 |

### 服务菜单功能
1. 👥 查看在线用户
2. 📁 文件传输
3. 🟢 设置在线状态
4. 🕶️ 设置隐身状态

## 📊 系统监控

项目包含一个 Fish 脚本 `my_top.fish`，用于实时监控系统性能：

**监控功能：**

- 📈 系统资源使用情况（CPU/内存）
- 🌐 端口监听状态检查
- 🔄 循环输出监控信息

```bash
# 运行监控脚本
./my_top.fish
```
